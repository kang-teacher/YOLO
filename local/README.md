# 파이참(내 컴퓨터)에서 데이터셋 만들기

코랩이 잘 안 될 때 쓰는 대안이에요. 결과물(`my_dataset.zip`)은 코랩 노트북에 그대로 올려 이어서 학습할 수 있어요.

```bash
pip install -U ultralytics pillow
```

| 파일 | 하는 일 |
| --- | --- |
| `label_tool.py` | `photos` 폴더의 사진을 한 장씩 띄우고 마우스로 바운딩 박스를 그려 YOLO 라벨을 저장. 끝내면 `my_dataset.zip` 생성 |
| `train_local.py` | `my_dataset` 을 train/val 로 나누고 YOLO26(`yolo26n.pt`)으로 학습 → `my_best.pt` |
| `webcam_test.py` | 학습한 모델로 웹캠에서 물체 찾기 |

## 순서

1. 세 파일을 파이참 프로젝트 폴더에 넣고, 같은 폴더에 `photos` 폴더를 만들어 사진을 넣어요.
2. `label_tool.py` 맨 위의 `CLASSES = ['cup']` 를 찾을 물체 이름(영어)으로 바꾸고 실행.
3. 사진 창을 클릭하고 드래그로 박스 → `Enter` 로 저장하고 다음 사진. 다 하면 `Q`.
4. 학습은 둘 중 하나
   - **추천:** `my_dataset.zip` 을 코랩 노트북의 2-A 셀에서 올리고 3번(확인)부터 진행 (GPU 라서 빠름)
   - `train_local.py` 실행 (GPU 가 없으면 느려요)

| 키 | 동작 |
| --- | --- |
| 드래그 | 박스 그리기 |
| 오른쪽 클릭 | 그 자리의 박스 지우기 |
| `Enter` / `Space` | 저장하고 다음 (박스가 없으면 한 번 더 눌러야 빈 사진으로 저장) |
| `Z` / `C` | 마지막 박스 지우기 / 모두 지우기 |
| `A` / `D` | 이전 / 다음 (저장 안 함) |
| `1`~`9` | 클래스 바꾸기 |
| `Q` / `Esc` | 끝내기 |

창 안의 안내 글자는 OpenCV 가 한글을 못 써서 영어로 나와요. 한글 폴더 이름이어도 동작해요.
