# 파이참에서 내 모델 학습하기

웹페이지 6단원에서 만든 **데이터셋 zip** 으로 나만의 YOLO 모델을 학습해요.
사진 찍기와 상자 그리기는 웹페이지에서 끝났으니, 여기서는 **학습과 시험만** 해요.

```
웹페이지 (사진 모으기 → 상자 그리기 → zip 내려받기)
   ↓
파이참   1 가져오기 → 2 학습하기 → 3 사진 시험 / 4 웹캠 시험
```

물체 이름(`CLASSES`)과 데이터셋 이름(`PROJECT_NAME`)은 **zip 안에 들어 있어서 자동으로 적용돼요.** 코드를 고칠 필요가 없어요.

## 준비 (처음 한 번만)

1. 이 폴더의 파일을 모두 파이참 프로젝트 폴더에 넣어요. (한글 폴더 이름이어도 괜찮아요)
2. 파이참 아래쪽 **Terminal** 에서 설치해요.

   ```bash
   pip install -U -r requirements.txt
   ```

## 순서 (파일을 열고 ▶ Run)

| 순서 | 파일 | 하는 일 | 생기는 것 |
| --- | --- | --- | --- |
| 1 | `1_데이터셋_가져오기.py` | zip 을 찾아서 풀고, 물체 이름·데이터셋 이름을 자동으로 읽어요 | `datasets/이름/`, `확인_그림.jpg` |
| 2 | `2_학습하기.py` | 내 사진과 상자로 YOLO 를 학습해요 | `이름_best.pt` (내 모델), `runs/이름/results.png` |
| 3 | `3_사진으로_시험하기.py` | `시험사진` 폴더의 새 사진으로 시험해요 | `시험결과/` |
| 4 | `4_웹캠으로_시험하기.py` | 웹캠으로 내 모델을 써 봐요 (`q` 로 끝) | |

`공통.py` 는 모든 파일이 같이 쓰는 설정이라 실행하지 않아요.

### 1번: zip 은 어디에 두나요?

- 웹페이지에서 내려받은 그대로 **다운로드 폴더**에 두면 가장 최근 zip 을 알아서 찾아요.
- 이 폴더에 넣어 두면 그걸 먼저 써요. (다운로드 폴더에 zip 이 여러 개라 헷갈릴 때)
- 사진을 더 찍어서 zip 을 새로 받았다면 **1번부터 다시** 실행하면 돼요.

실행하면 이렇게 나와요.

```
📦 찾은 zip: C:\Users\...\Downloads\my_cup_dataset.zip
🏷️ CLASSES      = ['cup']
📁 PROJECT_NAME = 'my_cup'
📊 데이터셋 살펴보기
   train: 사진 40장 (그중 물체 없는 사진 3장)
   val  : 사진 10장 (그중 물체 없는 사진 1장)
          cup: 상자 52개
```

`datasets/my_cup/확인_그림.jpg` 를 열어서 상자가 물체에 잘 맞는지 확인해 보세요.

### 2번: 학습하는 동안 화면 읽는 법

```
      Epoch    GPU_mem   box_loss   cls_loss   dfl_loss  Instances       Size
       5/30         0G      1.234      2.345      1.456         12        640
                 Class     Images  Instances      Box(P          R      mAP50  mAP50-95)
                   all         10         13      0.812      0.769      0.834      0.512
```

| 글자 | 뜻 | 좋아지는 방향 |
| --- | --- | --- |
| `Epoch 5/30` | 전체 train 사진을 30번 반복해서 공부하는 중 5번째 | |
| `box_loss` | 상자 위치를 얼마나 틀렸는지 | ⬇ 내려가야 해요 |
| `cls_loss` | 물체 이름을 얼마나 틀렸는지 | ⬇ 내려가야 해요 |
| `mAP50` | 처음 보는 val 사진으로 친 시험 점수 (0~1) | ⬆ 올라가야 해요 |

학습이 끝나면 `runs/이름/weights/` 에 두 파일이 생겨요.

- `best.pt` : val 시험 점수가 **가장 좋았던** 순간의 모델 → `이름_best.pt` 로 복사해 둬요. 이걸 써요!
- `last.pt` : **마지막** 반복이 끝난 순간의 모델 (학습을 이어서 할 때 써요)

### 3번 · 4번: 내 모델 써 보기

수업 때 쓴 코드와 똑같아요. 모델 파일 이름만 바뀌어요.

```python
model = YOLO('yolo11n.pt')      # 수업 때: 80가지 물체

```

## 학습이 너무 느리면

`공통.py` 맨 위의 값을 바꿔요.

```python
EPOCHS = 10   # 반복 횟수 줄이기 (기본 30)
IMGSZ = 416   # 사진 크기 줄이기 (기본 640)
```

GPU 가 없는 노트북은 사진 50장 · 30번 반복에 수십 분 걸릴 수 있어요. 먼저 `EPOCHS = 10` 으로 끝까지 해 보고, 시간이 남으면 늘려요.

## 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| `데이터셋 zip 을 못 찾았어요` | 웹페이지 6단원에서 zip 을 내려받았는지 확인하고, zip 을 이 폴더에 직접 넣어요 |
| `No module named 'ultralytics'` | Terminal 에서 `pip install -U -r requirements.txt`. 파이참 인터프리터가 설치한 파이썬과 같은지 확인 |
| `yolo26n.pt` 가 없다는 오류 | ultralytics 가 옛 버전이에요. `pip install -U ultralytics` (8.4 이상) |
| 학습 점수(mAP50)가 너무 낮음 | 사진을 더 모으고(물체마다 30장 이상), 상자를 물체에 딱 맞게 그렸는지 `확인_그림.jpg` 로 확인 |
| 웹캠이 안 켜짐 | 다른 프로그램(줌 등)을 끄고, 맥은 시스템 설정 → 개인정보 보호 → 카메라에서 파이참 허용 |
